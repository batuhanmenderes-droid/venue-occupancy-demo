# Sunum şablonu (16:9)

Boş sunum şablonu: 1. slayt ürün mockup'ı + başlık, 2. slayt kopyalanacak boş slayt.

- `index.html`: slaytlar. Yeni slayt için bir `<section class="slide">` kopyalayın.
- `deck.css`: marka renkleri, tipografi, 1920 × 1080 tuval.
- `deck.js`: ekrana sığdırma, ← → / boşluk / kaydırma / dokunma ile gezinme, `#3` adresi, `F` tam ekran.
- `assets/app-map.jpg`: telefondaki ekran (ürünün harita görünümü).
- Yazdırma / PDF: tarayıcıdan yazdır, her slayt bir sayfa.
